# 数据管线文档导航

本模块负责接入原图和指标结果，形成固定划分、训练缓存与读取接口。先确认上游数据满足规范，再查看缓存格式和验证范围。

## 建议阅读顺序

1. 读[上游数据接入与当前边界](interfaces/上游数据接入与当前边界.md)，确认可接入的数据类型及尚未完成的交接。
2. 读[训练缓存格式规范 v1](interfaces/训练缓存格式规范_v1.md)，确认划分、缓存和样本内部字段。
3. 读[数据管线测试设计](validation/数据管线测试设计.md)，了解身份、有效性和数据泄漏等检查规则。
4. 需要追溯原交付结论时读历史交付记录，并以当前模块说明核对后来变化。

## 01 接口与交接

- [上游数据接入与当前边界](interfaces/上游数据接入与当前边界.md)：说明原图、指标和攻击观测的接入状态及身份匹配要求，准备输入数据时读。
- [训练缓存格式规范 v1](interfaces/训练缓存格式规范_v1.md)：定义 training-v1 的划分文件、HDF5 分片、样本字段和来源记录，实现转换或读取训练缓存时读。

## 02 验证与交付

- [数据管线测试设计](validation/数据管线测试设计.md)：说明输入校验、结果连接、划分、归一化和缓存提交的检查边界，新增功能或判断验证范围时读。
- [数据管线历史交付记录 0.2.0](validation/数据管线历史交付记录_0.2.0.md)：保留该次交付的功能、检查结果和未完成事项，需要追溯当时状态时读。

历史交付中的检查数字属于其注明版本；当前回归情况以模块说明和对应检查记录为准。
