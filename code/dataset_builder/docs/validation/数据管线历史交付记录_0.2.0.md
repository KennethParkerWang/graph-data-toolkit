## 完成的功能

- `graph_source.py`：graph-v1文件SHA/字节数、MAT类型/shape、A与边表、严格边序、N/M/方向、
  topology_hash、recipe_json原文身份和scientific_sha256校验。复用任务1的规范序列化；保留属性、
  孤立点、空边和来源边序的可用性，原边ID不重排。
- `source.py`：图/指标按graph_id和完整运行身份关联；初始化仅读元数据，MAT按需解析。
  已解析dataset/manifest/generation配置版本被固定；发布过程变化要求重新打开reader，防止旧行配新摘要。
  校验静态/summary及attack-1.0/1.1；complete不能包含未完成计算，sample状态与引用state逐项一致。
- `config.py/selection.py/projection.py`：显式feature/target及精确参数/版本/协议/repeat选择；
  observation_source为results/states/sampled，逐状态选择还须alignment=by_id。
  保留科学scope/值/dtype，增加observation轴，按原节点/边/矩阵/文字坐标对齐。
  不可达请求、重复请求、实际位置、每条状态/原因不丢失，不插值。
- `models.py/cache.py/batching.py`：present_mask区分已删除或未观测位置，valid_mask表达数学有效性；
  原始值与训练计算视图分开。training-v1的转换版本升为data-pipeline-v2，包含新语义的缓存ID。
- `splits.py/normalization.py`：基础/派生/重复拓扑传递分组，random/family/size按配置固定划分；
  只对训练特征拟合。完全缺失也核验指标与观测来源身份；目标和源文件不改写。
- `dataset.py`：按样本读取、每进程独立HDF5句柄；Torch/PyG均保留显式N和原始边映射。
  原生PyG入口与独立mask/padding入口均可用，不自动将全部指标塞入x/y。
- 三个验收入口：`producer_smoke.py`、`metric_smoke.py`、`producer_layout_benchmark.py`。
