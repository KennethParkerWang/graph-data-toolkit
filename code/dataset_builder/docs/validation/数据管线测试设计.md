# 数据管线测试设计

输入规范：任务 1 的 `graph_schema_v1.md` 与任务 2 的 `metric_schema_v1.md`。
独立框架测试使用 `models.py` 中的内存对象，不生成或宣称兼容未发布的原始格式。

| 层 | 必须断言的内容 | 失败行为 |
|---|---|---|
| 原始图 | 文件字节 SHA、schema、graph_id 配方、topology_hash、N/M、A/边表一致性、严格边序 | 明确报错，不排序修复 |
| 图编号 | 有向互惠弧、孤立点、空边集、双向展开后的原始边 ID | 不从最大端点推断 N |
| 关联 | graph_id + topology_hash + metric_set_id + protocol_id + run_id | 重复、缺失或冲突不可静默选择 |
| 选择 | 精确版本、参数、scope、协议、feature/target 独立列表 | 禁止全部指标自动成为特征 |
| 无效性 | 真实零、失败、未计算、不适用、未定义、局部无效 | 数值与 mask/status/reason 分开保留 |
| 轴 | 节点/边原始 ID、矩阵两轴 ID、变长轨迹的实际采样位置 | 重复汇总的轴不匹配即拒绝 |
| 观测投影 | states/sampled 显式选择；按原ID/文本坐标并集对齐；重复请求、已删除结构、源dtype和实际位置 | 缺席与数学无效分开；同alias不同来源即使全缺失也拒绝 |
| 攻击版本 | 1.0/1.1边界、fraction_grid请求/增量/轮次映射、空目标比例NaN、不可达exact样本 | schedule、执行状态或完整轨迹标志矛盾即拒绝 |
| 重复 | keep 保留 run_id；mean 保留有效数量、方差和来源 | 不覆盖原始重复结果 |
| 划分 | 派生与重复拓扑的传递闭包，同图所有攻击/重复同区 | 跨族/规模分组冲突必须显式处理 |
| 归一化 | 仅 train 有效特征拟合；验证/测试极值不得影响统计 | 未拟合或无有效训练值拒绝 |
| 缓存 | ID 依赖源校验、配置、split、schema 和转换；临时文件校验后提交 | 内容冲突/写入中断不发布 index |
| 按需读取 | 初始化不读图内容，多 worker 独立句柄 | 损坏分片或过期 provenance 报错 |
| CPU batch | num_nodes、边偏移、原始边 ID、ragged padding 与 mask | PyG 自动拼接不得改变原始轴语义 |

交接验证先读取任务 1/2 的少量新样本，逐值核对，再转换 HDF5、回读并组成 CPU batch。
测试记录应区分“内存框架通过”“正式 MAT 接入通过”“真实 MATLAB 生产者样本通过”，不能相互替代。

正式静态全链路：5 组匹配 graph-v1/metric-v1；输入原字节拷贝、逐项身份与值核对、同源 split、
cache fingerprint、Torch/PyG × 0/2 workers。指标侧独立验收：7 份基础+5份扩展 MATLAB 结果，
保留测试身份；N=0仅解析指标，不生成非法训练图。轨迹对应任务1真实图的联调需后续匹配样例。

压缩测试比较相同样本的无压缩、LZF、gzip-1 的文件体积、写入/读取时间，以及少量分片大小；
结果仅描述所测样本，正式大数据的参数需要重新实测。本任务不训练模型。
