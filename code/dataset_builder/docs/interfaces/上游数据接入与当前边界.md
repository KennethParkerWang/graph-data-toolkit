## 原始图校验

读取器核对文件字节数与SHA、严格MAT类型/尺寸、原始节点数、方向、空边形状、边序与唯一性、
A与edge_list一致性、topology_hash、保存recipe_json原文的graph_id，以及 scientific_sha256。
配方和科学内容规范序列化复用任务1发布的 `validation/verify_graph_io.py`，并记录其摘要。
不会排序修复原图或改变原始边ID。原来源边序可用但为空，与未提供来源边序保持区别。

SourceDataset初始化只读descriptor/manifest元数据，单图MAT按需加载；实际边表用于核验攻击
初始端点和原边ID。读取过程必须固定已解析的元数据发布版本；发布变更要求重新打开reader。

新版批量descriptor的generation字段按整组校验：固定相对路径、SHA格式、配置文件字节摘要、
schema_version=2、dataset_id及便携output_dir。手工格式夹具可以不带此组字段。
generation_config_sha256作为上游配置身份保留；本模块不以Python JSON重新实现MATLAB
默认值展开/规范化身份算法，也不声称已经独立重算这一配置身份。单图配方与科学摘要仍逐图实核。

## 指标与观测校验

- exact identity JSON/hash、graph与run身份、完整参数/版本、protocol配置、seed与RNG一致性。
- sampled值/轴/mask/状态与引用的state完全相同；删点连带边、存活ID、原始端点、批量边界、
  请求舍入及exact/previous/next采样策略逐项检查。
- `complete`不能包含failed/not_computed的已执行指标；不可达的sample请求不计作执行失败。
- 1.1的schedule逐字段验证，含重复请求、零增量、实际state_index/round_index、空目标NaN。
- unavailable无轴空结果保留shape_unknown，不臆造标量；合法数学+Inf仅由具体注册定义授权，
  保留原值和mask，重复均值/训练标准化仍拒绝隐式处理有效Inf。
- 显式 observation_source=states|sampled、alignment=by_id 才投影逐步指标；默认 results 包括
  summaries。按实际原ID/文本坐标合并轴，增加observation首维，不插值、不修改科学scope。
- present_mask与valid_mask分离；完全缺失也保留来源身份并核验，不能绕过版本或来源冲突。
