# 训练缓存格式规范_v1

本规范仅定义 `dataset_builder` 写出的可重建 HDF5 缓存。原始图由任务 1 的
`graph_schema_v1.md` 定义，指标由任务 2 的 `metric_schema_v1.md` 定义。
本模块不发布替代原始 MAT 格式。当前上游接入状态见 [上游数据接入与当前边界](上游数据接入与当前边界.md)。

## 路径、身份与版本

正式数据的输出路径：

```text
datasets/<dataset_id>/
  splits/<split_id>.json
  training/<cache_id>/
    index.json
    shard_00001.h5
    shard_00002.h5
```

独立框架测试将输出放到 `dataset_builder/artifacts/`，并记录 `fixture_only=true`。
这些内存样例不等同于生产者 MATLAB 文件验收。

- `schema_version=training-v1`；新转换使用 `conversion_version=data-pipeline-v2`。
  v2 增加观测投影的 `present_mask` 与来源身份校验，缓存 ID 与本任务上一版自动区分；
  只读器仍能校验本任务此前写出的 v1 缓存。此规则不涉及以前项目的原始格式。
- `cache_id` 是 schema、转换版本、完整 provenance、分片/压缩设置的规范 JSON SHA-256。
- `content_id` 是排序后 `(sample_id, fingerprint)` 列表的 SHA-256。
- 每个 fingerprint 包含原图身份/N/方向/边表/来源顺序、选中的值/mask/轴/状态/定义和来源。
- `index_sha256` 校验除自身外的完整索引。每个分片另有文件字节数和 SHA-256。
- 生产转换 provenance 包含 dataset/manifest/schema 文档摘要、源文件声明校验、完整选择配置、
  固定 split、归一化状态和转换版本；转换结束重新核对源快照。

移动整个数据集不改变 cache_id。索引的分片路径相对于 cache 目录。
`TrainingDataset(expected_provenance=...)` 可检查调用者期望的源快照；单独读取历史缓存只验证
其自洽性，不自动承诺它对应外部数据集的最新状态。更新源/配置时重新运行转换会产生新 cache_id。

## 索引与分片结构

`index.json` 包含 `schema_version`、`conversion_version`、`cache_id`、`content_id`、
`provenance`、`options`、`sample_count`、`samples`、`shards` 和 `index_sha256`。
每条 samples 记录 `sample_id, graph_id, split, shard, group, fingerprint`；只含定位元数据。

```text
shard_00001.h5
  attrs: schema_version, cache_id
  samples/000000000/
    record                  UTF-8 JSON：图身份、N、方向、元数据、split、来源
    edge_list               M×2：原始 1-based 规范边表
    source_edge_order       可选：原始来源边序映射
    features/<ordinal>/
      definition            UTF-8 JSON：key、指标ID/版本/参数/scope/轴名/状态/原因/元数据
      values                原逻辑 shape 和数值 dtype
      valid_mask            同 shape bool
      present_mask          可选，同 shape bool；结构上存在的源单元
      node_ids              可选，原始节点 ID
      edge_ids              可选，原始边 ID
      axis_ids/<ordinal>/
        name                UTF-8 JSON 轴名
        values              原始轴 ID 或文本坐标向量
      axis_positions/<ordinal>/
        name                UTF-8 JSON 位置名称
        values              实际采样位置向量
    targets/<ordinal>/      与 features 完全相同
```

ordinal 只用于 HDF5 内部组织，指标关联使用 definition 中的显式 key。
MATLAB scalar 恢复逻辑 0 维；一条命名轴恢复逻辑 1 维；矩阵恢复对应的两条轴。
无轴且不可用的空结果保留原始空 shape，并设置内部 `shape_unknown=true`。
不根据节点数猜缺失结果的形状。

JSON 中数值数组使用 `{"__array__":...,"dtype":...,"shape":...}` 编码；非有限元数据
使用 `{"__nonfinite__":"nan"}` / `"inf"` / `"-inf"` 编码，读取时恢复。
values 和坐标数组直接保存在 HDF5 dataset 中。
source 定义允许的有效 +Inf 保持原值与有效 mask；平均/标准化不能隐式改其意义。
文本坐标（例如 HITS 的 hub/authority 轴）采用 HDF5 UTF-8 字符串保存，并记录 NumPy dtype，
回读恢复原字符串坐标，不将它们伪装为数值节点编号。

## 指标选择与重复

`SelectionConfig` 的 `feature_keys`、`target_keys` 分别将用户别名映射到以下精确选择：

```json
{
  "metric_id": "REPLACE_WITH_PUBLISHED_METRIC_ID",
  "metric_version": "REPLACE_WITH_PUBLISHED_VERSION",
  "parameters": {},
  "scope": "node",
  "metric_set_id": "REPLACE_WITH_PUBLISHED_METRIC_SET_SHA256",
  "protocol_id": ""
}
```

参数必须填写生产者展开后的完整参数。支持 graph/node/edge/distribution/matrix/trajectory。
静态 protocol_id 显式为空；攻击使用精确发布 ID。不同攻击协议不混入一个样本配置。

`repeat_mode=keep|mean`、`missing=error|mask`、`run_ids=all|[IDs]` 必须显式提供。
缺失策略仅控制真正缺失，不放过版本/参数/拓扑冲突。failed、undefined、not_applicable、
not_computed 仍保存各自状态和原因。真实 0 与 invalid/padding 依靠 mask 区分。

不同指标集的 run_id 不相等。各静态指标集只有一个运行时，按图组合成一个样本；唯一静态
运行也可作为显式选定攻击流的输入特征。独立重复流使用配置中的可选绑定：

```json
{"run_groups": {"GRAPH_ID": {"sample_a": {"METRIC_SET_A": "RUN_A", "METRIC_SET_B": "RUN_B"}}}}
```

绑定时 run_ids 必须为 all，每个 sample_key 指明每个选中指标集的 run_id。
不能用文件序号、相似 seed 或位置推测配对。
mean 只对同定义、同实际轴/ID/位置的有效值计算，保留逐位置 count、总体方差
(`ddof=0`) 和各运行状态/来源，不覆盖原始重复。位置或长度不同需要另行显式派生转换；
当前不会自动插值。有效非有限值的平均/拟合会报错。

默认 `observation_source="results"` 选择生产者的 `results` 和 `summaries`，包括已定义的轨迹指标。
直接选择逐状态或比例取样中的指标时，必须同时指定来源和对齐方式，例如：

```json
{
  "metric_id": "degree",
  "metric_version": "1.0.0",
  "parameters": {},
  "scope": "node",
  "metric_set_id": "REPLACE_WITH_ACTUAL_METRIC_SET_ID",
  "protocol_id": "REPLACE_WITH_ACTUAL_PROTOCOL_ID",
  "observation_source": "states",
  "alignment": "by_id"
}
```

示例中的参数和 ID 必须替换为所选生产者配置，不能据此推定已计算 degree。
`states` 保留每个真实状态；`sampled` 保留每个原请求及顺序，包括重复映射至同一状态的请求。
转换增加首轴 `observation`，其他轴取实际出现过的原 ID/坐标并集，按首次出现顺序对齐。
节点/边 ID、矩阵两轴、字符串或分布坐标均按原值关联；不按向量位置配对，不插值。
scope、指标 ID/版本/参数、源值 dtype 和全部实际值不变。

结构删除或未观测的位置 `present_mask=false`；已计算但数学无效的位置
`present_mask=true, valid_mask=false`。浮点缺席单元为 NaN，整数/布尔缺席单元为 0，
这些填充值均不成为有效训练值。无任何已知 rank/轴时保留 `shape_unknown`，不臆造标量。

`metadata.observation_projection` 记录转换版本 `observation-by-id-v1`、source/alignment、
每条原观测的状态/原因、坐标、dtype、轴与源元数据。`axis_positions` 保留原字段名：
states 的 `removed_count/removed_fraction/round_index/state_index/fraction_valid`，sampled 的
`requested_fraction/requested_removed_count/actual_removed_count/actual_removed_fraction/state_index/`
`fraction_valid/exact_count_match`，并通过 `axis_position_axes` 映射到 observation 轴。
不可达的 exact 请求保持 `state_index=0`、实际位置 NaN、not_computed；missing=error 拒绝，
missing=mask 保留缺席位置。原协议 schedule 和删除路径保留在来源 provenance。

攻击 `1.0.0` 与 `1.1.0` 分别校验版本语义；fraction_grid 的请求、舍入、增量、状态/轮次映射
逐项核验。空目标集的实际比例始终为 NaN，不能变成 0 或 1。
重复均值要求真实/请求位置、坐标和顺序一致，保留有效 `count`、结构 `present_count`、方差及
各 run 的投影元数据。同 alias 的 states/sampled 身份不混用，即使其中一方完全缺失也拒绝。

## 分区与归一化

split-manifest-v1 记录全部图身份、分组、分配、排除原因、规则和 split_id。
对 origin_graph_id、已知 parent_graph_id(s)、完全相同 topology_hash 做传递合并；
缺席的基础图也作为组关联节点。整个组只进入一个分区。

- random：显式 train/val/test fractions 与 seed，以组 ID 的确定性 hash 分配；小样本比例未必精确。
- family：明确每区的模型列表。
- size：明确每区的 N 闭区间，null 表示开放端。
- 跨区组冲突：error / exclude / assign；assign 必须显式绑定整组，排除记录保留原因。

固定 split 不覆盖不同内容。新增图/派生关系或规则变化必须生成新的 split。
命令行不预选正式划分方案。

可选标准化按每个 feature alias 的有效数值汇总均值/总体方差；所有维度合并统计，
不是每节点或每曲线位置单独拟合。仅 train 样本参与，记录训练图/样本 ID。
常数特征 scale=1，无有效训练值报错。targets 保持原值；源 MAT 文件始终保留。

## 按需读取与 batch

`TrainingDataset` 初始化仅读 index；getitem 打开单分片并读取单样本。
每进程独立维护 HDF5 句柄，pickle 不携带句柄，默认最多缓存 8 个分片句柄。
每次打开分片核对文件校验，每次取样核对内容 fingerprint。

边的转换只发生在模型读取层：`M×2, 1-based -> 2×E, 0-based`。
可配置将无向边展开为正反两向；有向弧原样保留。`original_edge_id` 始终指向原始 1-based
边表行号，双向展开的两条消息边使用同一个原始 ID。PyG 的 num_nodes 显式取 N，保留孤立点和空边集。

每个指标独立按当前 batch 最大尺寸 padding，返回：

- `raw_values`：源值视图，invalid NaN/Inf 保留；`values`：计算视图，invalid/padding 填 0。
- `valid_mask`：训练使用的有效位置；`present_mask`：该位置确有源结果，区分缺失/padding。
- `shapes`、`status`、`reason`、`axis_names`、原始 node_ids/edge_ids/axis_ids。
- `axis_positions`：每种实际位置独立 padding，附存在 mask；不制造等距采样点。

数值轴的 values 返回 Tensor；文本 axis_ids 的 values 返回嵌套字符串/None 列表，
present_mask 仍为 Tensor，shapes 保留实际尺寸。

`make_torch_loader` 直接返回上述字典。`make_pyg_loader` 另外返回 PyG `graph_batch`，
拓扑正确偏移，指标仍独立 padding。`PyGTrainingDataset` 可交给原生 PyG DataLoader；
其 `training_sample` 列表保留原始变长对象。指标不会自动全部变成 x 或 y。
训练调用者必须使用目标的 valid_mask。多 worker 的 Windows 入口必须置于 `if __name__ == '__main__'`。

接口依据：[PyTorch DataLoader](https://docs.pytorch.org/docs/stable/data.html)、
[PyG batching](https://pytorch-geometric.readthedocs.io/en/latest/advanced/batching.html)。

## 写入、压缩与失败

每个 cache 目录使用独占 `.writer.lock`；每个分片只有一个写入者。
临时分片完成后逐样本回读核验，计算文件摘要，再提交分片，最后发布 index。
异常不发布 index；进程崩溃遗留的 lock/未登记分片需要核对原进程已结束后人工恢复。
不自动删除来源、覆盖冲突缓存或把文件存在视为完成。

分片按显式样本数上限写入。支持 none/lzf/gzip；非空非标量 dataset 才应用压缩。
CLI 要求显式 shard-size/compression。`framework-smoke` 测试 2/8 样本分片及三种压缩，
记录本机实测体积与时间。`producer_smoke` 对 5 组正式 MATLAB 图/静态指标记录分片回读和
冷/热读取时间；这里的冷读是新句柄，未清理操作系统页缓存。该小样本结果不能推出生产最优参数。
