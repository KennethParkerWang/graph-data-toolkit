# 基础图指标定义与验证

Version: 1.0.0. Runtime: MATLAB R2024b. All functions consume `mc.context`, whose adjacency convention is `A(source,target)=1`. No raw-graph format is defined here. Every item has a separate `+mc/+metrics/<metric_id>.m` function and can be selected independently through `mc.compute`.

## Implementations and source policy

MATLAB `graph` / `digraph`, `conncomp`, `distances` and `maxflow` supply tested graph primitives under the installed MATLAB license. Implemented formulas and standard algorithm descriptions are original MATLAB code. No NetworkX or author source file is bundled, translated verbatim or copied; upstream source was inspected to resolve definitions. The independent comparison uses **NetworkX 3.5** (BSD-3-Clause), already installed; it is not a MATLAB runtime dependency. See [upstream license](https://raw.githubusercontent.com/networkx/networkx/networkx-3.5/LICENSE.txt). No redistribution license is claimed for MATLAB itself.

Brandes dependency accumulation follows [Brandes 2001](https://doi.org/10.1080/0022250X.2001.9990249); the adjacency BFS, predecessor lists and reverse dependency accumulation preserve exact unweighted shortest-path semantics. Floating path multiplicities are checked for overflow. Iterative Tarjan low-link search identifies undirected bridges and articulation points without recursion depth limits. K-core peeling removes minimum current total degree; directed reciprocal arcs contribute twice.

## Conventions and limits

- Empty count metrics are zero; empty node/edge vectors are empty with valid shape. Means on an empty population are undefined. Density, reachable-pair fraction and global efficiency require at least two nodes and otherwise return NaN with a false mask.
- Degree variance is population variance (division by N). Heterogeneity is `<k^2>/<k>^2`, undefined if mean degree is zero. Distribution axes include all degrees from zero to the largest degree; empty-node distributions are undefined.
- Components default to `component_mode=weak`; directed strong components require `strong`. Undirected accepts either and uses connected components. Component labels are local membership labels, not canonical graph identities. Largest-component fraction uses the **current** node count. Missing largest/second-largest component sizes are zero.
- Bridges and articulation points are undirected only. Point/edge connectivity is the minimum pairwise local connectivity; n<2 is undefined, disconnected (or not strongly connected) is zero. Vertex splitting with unit node capacities and unit original-arc capacities computes internally vertex-disjoint paths, including a direct path between adjacent endpoints. Complete directed/undirected graphs have connectivity n-1.
- Distance matrices have source rows and target columns. Diagonal is zero; unreachable distance is `Inf` with a **true** validity mask. Eccentricity, radius and diameter retain meaningful `Inf`. Singleton eccentricity/radius/diameter is zero; empty graph radius/diameter is undefined.
- Mean path length defaults to all distinct ordered pairs and is undefined if any such pair is unreachable. `pair_policy=reachable` averages only finite distinct pairs; no eligible pairs is undefined. It never silently selects a largest component.
- Global efficiency uses ordered pairs, with reciprocal unreachable distance zero. Local efficiency returns one value per undirected node, using its induced open neighborhood; neighborhoods below size two have zero by explicit convention. Directed local-neighborhood efficiency requires a separate definition and is not exposed.
- Undirected triangle counts are exact integer counts. Directed local clustering uses Fagiolo 2007, `diag((A+A^T)^3)/(2*(k_total*(k_total-1)-2*k_recip))`. Clustering denominator zero gives zero by convention; mean clustering includes these zeros. Transitivity with no connected triples is undefined (deliberately stricter than the NetworkX zero convention).
- Square clustering uses the **Zhang 2008 union-neighborhood denominator**, matching NetworkX 3.5, not the older product-denominator variant. For neighbor pair u,w, `q=|N(u) intersect N(w)|-1`; denominator contribution is `k_u+k_w-2-2*A_uw-q`. No possible square gives zero. This variant is stated in the metric definition and must not be interchanged with older variants.
- Directed triad census counts **induced** three-node graphs in the fixed 16-class sociological order. It includes null/disconnected triads. It is a count, not motif significance; no null model is invented. The implementation enumerates all unordered triples and classifies mutual dyads and degree patterns, without importing an upstream lookup table.
- Closeness defaults to **outgoing** distances and Wasserman-Faust correction `reachable_count/(N-1)`. Isolates and singleton nodes have zero. Incoming closeness uses `direction=in`. Harmonic centrality defaults to raw reciprocal-distance sum; normalized form divides by N-1 and is undefined for singleton nodes.
- Betweenness excludes endpoints, sums unordered pairs for undirected and ordered pairs for directed, and defaults to unnormalized. Normalized node denominators are `(N-1)(N-2)/2` undirected and `(N-1)(N-2)` directed. Edge denominators are `N(N-1)/2` and `N(N-1)`. A nonpositive requested denominator yields invalid values. Edge output order follows `ctx.edge_list` and `ctx.edge_ids`, never MATLAB graph internal edge order.
- Eigenvector centrality is the incoming nonnegative Perron vector of A transpose, normalized in L2. This implementation requires a connected undirected or strongly connected directed graph with at least one edge, so uniqueness is justified. Disconnected/reducible cases are reported undefined rather than returning an arbitrary eigenspace vector. Dense eigensolve residual and nonnegativity are checked.
- Katz requires explicit `alpha`, checks `alpha*rho(A)<1`, uses positive scalar beta, and solves `(I-alpha*A transpose)x=beta*1`; L2 normalization defaults true. PageRank follows outgoing edges, uses uniform teleportation and uniform dangling redistribution, and checks L1 iterate differences. HITS starts at a uniform positive hub vector and alternates A transpose/A products; hub and authority columns each sum to one. In a degenerate leading singular subspace, the uniform-start projection defines the result; uniqueness is not claimed. Iteration exhaustion returns failed with an empty result and diagnostics.
- All computations are deterministic; there is no graph sampling, randomized initialization, approximation or hidden switch of methods. Size guards explicitly reject an expensive requested computation. Distance default `max_nodes=5000` (dense N-by-N memory); point/edge connectivity and cubic triads default 200; dense eigenvector/Katz default 2000. Users can consciously raise limits. Registry complexity and parameters distinguish exact combinatorial from numerical calculations.

## Reproducible verification

`python tests/reference_basic.py` writes `validation/basic_reference.json` from NetworkX **3.5**. It covers 11 fixtures: empty, singleton, five isolates, P4, C4, S5, K4, multiple components, directed path, directed cycle and a mixed directed graph. It also labels all 64 directed adjacency patterns on three nodes.

In MATLAB, add the library and tests folders, then call `report=test_basic()`. Every registered basic function is invoked directly and through the dispatcher on all compatible fixtures. Reference comparisons use absolute/relative tolerance 1e-8; exact structural values are integer-valued. Further checks cover node permutation covariance, edge ID preservation, incoming versus outgoing centrality, disconnected behavior, normalization, HITS fixed-point equations, invalid attenuation, resource limits and deliberate nonconvergence.

The reference intentionally excludes numerical/eigenvalue cases in which another implementation chooses a different representative of a nonunique eigenspace. HITS is checked by its two defining equations and deterministic initialization. No large production calculation is launched. Final pass counts and timing appear in `validation/basic_test_report.mat` and `validation/basic_test.log`.

Directed vertex connectivity is compared against the minimum of **all ordered pairwise** NetworkX 3.5 local `node_connectivity(G,s,t)` values. Its global shortcut yields 1 on a directed four-node path, although an unreachable ordered pair has local connectivity 0. The library defines global directed connectivity through strong connectivity and the all-pairs minimum; it does not inherit that shortcut behavior.

Validated on MATLAB R2024b: `test_basic` passed **987 checks** in 4.737 seconds (small fixtures only). Counts measure grouped assertions and comparisons, not 987 separate graph inputs. The registry records this status. Additional axis-length checks ensure persisted vectors/matrices satisfy the schema.

Additional algorithm sources: [Tarjan 1972 low-link search](https://doi.org/10.1137/0201010); [Batagelj and Zaversnik 2003 core decomposition](https://arxiv.org/abs/cs/0310049). The present core peeling scans for the current minimum and therefore has O(N^2+M) complexity; it does not claim the paper's linear-time bin implementation.
