# 指标模块内部接口

`ctx = mc.context(A,directed,node_ids,edge_list,edge_ids)` accepts an in-memory simple unweighted graph, not a persisted graph record. Last three arguments optional for direct calculation only. ctx has A (sparse double), directed (logical), n, m, node_ids (column uint32), edge_list (local endpoint rows), edge_ids (column uint64), G (MATLAB graph/digraph), cache (mc.Cache handle containing a data struct). Never assume G.Edges order equals edge_list order.

Each independent function is `r = mc.metrics.<metric_id>(ctx,p)` with optional scalar parameter struct p. Common helper: `mc.param(p,name,default)`; reject unknown parameters through registry `parameter_defaults` (empty struct if none). Mandatory parameters use `required_parameters` string list. Defaults are merged before calling.

Result helper: `mc.make_result(id,values,scope,axis_names,axis_ids,valid_mask,status,reason)`; last four optional. axis_names cell array of char; axis_ids cell array (one numeric or text ID array per logical axis). Scope graph/node/edge/distribution/matrix/trajectory. Default mask is isfinite(values); callers override when infinity is mathematically meaningful. Status ok/partial/undefined/not_applicable/not_computed/failed. Unavailable result: empty values/mask and non-ok status with reason. Values are numeric/logical; extra detail goes into r.details struct. Standard fields metric_id,metric_version='1.0.0',parameters,scope,values,axis_names,axis_ids,valid_mask,status,reason,units,method,elapsed_seconds,details. Dispatcher fills parameters, elapsed_seconds, method and version from registry. Direct functions may fill method/details as appropriate.

Registry fragments `registry/<group>.json`: JSON array entries sharing fields metric_id,name,category,metric_version,definition,formula,sources (array of source IDs or URLs),source_version,license,graph_types (array directed/undirected),scope,complexity,method,parameter_defaults (object),required_parameters (array),implementation_status='implemented',validation_status,conditions. Root dispatcher loads all fragments; names map to mc.metrics.metric_id. Documentation for each group must map entries to source versions/licenses, methods and edge cases. Each group supplies `tests/test_<group>.m` simple function returning a struct counts/details or error; use assert. Root runs them. No edits outside owned files.

## Follow-up APIs

- `mc.attack_schedule` plus `mc.validate_attack_schedule`: version-aware round boundaries and request-to-state mapping; the latter checks saved scheduling semantics without resolving current ranking registry versions.
- `mc.match_metric` / `mc.attack_curve`: exact source parameters and optional version selection, including simultaneously observed weak/strong components.
- `mc.aggregate_repeats(root,records,selection,options)`: checked saved runs to independent repeat statistics.
- `mc.repeat_statistics(values,valid,options)`: rows=observations, columns=repeats; reusable numerical core without provenance assertions.
- `mc.validate_repeat_summary`: internal identity, shape and numerical consistency; source binding is additionally checked by `mc.save_repeat_summary`, which rereads and re-extracts verified observations before saving.

`[ctx,identity,record]=mc.read_graph(graph_path)` is now bound to task1 graph-v1. It requires the canonical graph path and its published graphs.jsonl row, delegates all scientific/hash validation to official readers, preserves IDs and optional source_edge_order, and restores the prior MATLAB search path. It never writes the graph or its index.
