# 指标计算文档导航

本模块负责计算原图指标、执行攻击实验并保存分析结果。指标定义、攻击协议和结果格式分别查阅。

## 建议阅读顺序

1. 读[基础图指标定义与验证](metrics/基础图指标定义与验证.md)及所需的其他指标定义，先确定要计算什么。
2. 读[指标结果存储规范 v1](metric_schema_v1.md)，确认结果字段、身份和有效性标记。
3. 进行攻击实验时读[攻击协议与鲁棒性摘要](attack_protocols.md)，再按需读比例网格和重复统计规范。
4. 开发接口或交给数据管线时读开发与交接类文档。

## 01 指标定义

- [基础图指标定义与验证](metrics/基础图指标定义与验证.md)：说明计数、度、连通性、距离等基础指标及边界约定，选择基础指标时读。
- [相关性社区谱与可控性指标](metrics/相关性社区谱与可控性指标.md)：说明相关性、社区、谱、电学和可控性指标的参数与适用条件，选择这些指标时读。
- [单节点与单边删除影响指标](metrics/单节点与单边删除影响指标.md)：说明单次对象删除后的影响定义和身份对应关系，比较节点或边的删除影响时读。
- [指标扩展条件与未支持情形](metrics/指标扩展条件与未支持情形.md)：说明需要额外科学选择或输入的扩展，以及当前拒绝或未支持的情况，判断一个指标请求能否直接计算时读。
- [指标结果存储规范 v1](metric_schema_v1.md)：定义 metric-v1 的保存路径、身份、字段和有效性规则，实现读写或核对正式结果时读；该文件是固定规范入口。

## 02 攻击与统计

- [删点删边与连通性鲁棒性](attacks/删点删边与连通性鲁棒性.md)：说明连通性相关指标、删点删边曲线和鲁棒性定义，选择连通性分析方案时读。
- [攻击协议与鲁棒性摘要](attack_protocols.md)：说明攻击目标、排序策略、采样与摘要规则，配置或解释攻击实验时读；该文件是固定协议入口。
- [累计比例网格攻击规范](fraction_grid_attacks.md)：说明累计攻击比例如何映射到实际删除轮次和观测位置，使用 fraction_grid 模式时读；该文件是固定协议入口。
- [独立重复统计规范](repeat_statistics.md)：说明已保存重复实验的聚合、校验和单独保存规则，计算均值、波动或置信区间时读；该文件是固定统计入口。

## 03 开发与交接

- [指标模块内部接口](development/指标模块内部接口.md)：说明计算上下文、结果封装、注册表和扩展接口，开发或修改指标实现时读。
- [指标结果交接记录](development/指标结果交接记录.md)：记录交接样例、跨语言读取检查和后续边界，接入样例或追溯交接结果时读。

交接记录保留原验收时间与范围，不能据此推断所有正式攻击结果已经完成训练数据接入。
