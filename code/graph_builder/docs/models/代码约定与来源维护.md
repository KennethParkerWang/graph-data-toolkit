# 代码约定与来源维护

当前为2.1.0，提供23个命名模型、27个可用接口（17无向、10有向），另12个旧方向入口明确报错。公共生成函数遵循`[A,meta]=gen_<model>_<direction>(...,seed)`；seed最后且默认1。默认值写入meta.parameters，API参数名与元数据字段名一致。

- 生成函数只返回图和元数据，不负责文件、绘图或训练。
- 每次调用用gg_seed恢复外部RNG，成功和失败都恢复。
- 有向A(i,j)=1表示i到j；无向严格对称。输出sparse logical、无自环、无重边，孤立点保留。
- gg_finalize记录临时生成元数据；gg_prepare_metadata补充出处、实现摘要并将模型附加信息放入attributes；gg_io_make_sample封装正式graph-v1字段。
- 源码指纹覆盖common、directed、undirected下的全部.m及两份模型来源catalog，按相对路径排序后hash。文档、批量运行控制和I/O不改变生成器指纹。
- 新增生成器先固定参考版本和许可证，再写参数、构造规则、异常与对照测试。不得靠随机定向或投影凑齐方向数量。
- 优化不能改变初始化、条件概率、候选限制、更新顺序和成功终止规则。条件分布等价但随机数消费不同的替换必须明确说明，不能声称同seed逐样本等价。
- 作者源码的异常路径保留在日志中。更改算法以修复来源缺陷时应另立协议/版本，不能沿用旧配方冒称原版。
- 连通条件按模型定义记录：复制—分化拒绝零边复制是采用来源的生成条件，Forest Fire的弱连通来自单起点增长；不要额外筛选失败样本或将条件生成写成独立边模型。
- 请求参数与实际结构分开保存：LFR保留目标度、实际度及实际混合比例；DC-SBM标明Poisson简单图投影；有限度保持交换标明非均匀；RHG保存极坐标；Forest Fire记录零起点几何与新节点到旧节点的弧方向。

来源文件按固定版本保存在[标准来源目录](../../sources/standard)与[作者来源目录](../../sources/author_lou)。来源记录与实现指纹会读取catalog，正式图元数据的出处检查还会读取对应参考文件及作者原包摘要，因此它们是来源完整性检查的依赖。NetworkX固定3.5并保留BSD-3-Clause，整数集合helper保留CPython的PSF许可。新增DC-SBM、RHG和Forest Fire依据论文自主实现，未将外部代码抄入；SNAP仅用于Forest Fire规则核对，保留出处引用。指定度序列使用独立Havel–Hakimi实现与有限交换方案，不冒称NetworkX随机度序列逐行移植。作者ZIP未发现通用开源许可证，按未授权状态记录；公开候选范围见[发布准备](../../../../README.md#发布准备)。

模型和代码的逐项关系见[标准模型](标准图模型与来源说明.md)、[扩展模型](合成网络扩展模型与验证说明.md)、[作者模型](作者图模型与已知边界.md)。旧1.1.0审计保存在项目根目录的 `_local/history/graph_builder/docs/model_source_audit.md`，用于追溯修改原因，不描述2.1.0的当前行为。
