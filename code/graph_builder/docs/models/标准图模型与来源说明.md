# 标准图模型与来源说明

本页说明任务1采用的具体来源协议。旧版 `model_source_audit.md` 审计的是 1.1.0；本页给出修改后的实现。

**2026-10-07扩展入口：** [合成网络扩展模型与验证说明](合成网络扩展模型与验证说明.md)记录2.1.0新增的7个模型。以下既有16个标准接口的来源和历史验证正文保留；当前总数23个命名模型、27个可用方向接口，以[参数手册](../usage/图生成模型与参数手册.md)和扩展专题为准。

## 可用接口

标准模型共保留16个接口：11个无向、5个有向。另4类作者模型由 `作者图模型与已知边界.md` 说明。

| 模型 | 无向 | 有向 | 参数（最后一个参数均为seed，默认1） |
|---|---|---|---|
| ER Gnp | 支持 | 支持 | N, p |
| ER Gnm | 支持 | 支持 | N, M |
| BA | 支持 | 暂不提供 | N, m |
| 静态SF | 支持 | 支持，原生双权重 | 无向 N, M, sigma；有向 N, M, sigma_out, sigma_in |
| WS | 支持 | 暂不提供 | N, K, beta；K是每侧邻居数 |
| NW | 支持 | 暂不提供 | N, K, beta |
| QS | 暂不提供 | 支持，单r层 | N, r, q |
| SBM | 支持 | 支持 | sizes, P |
| RGG | 支持 | 暂不提供 | N, radius, dim；dim默认2 |
| 随机正则 | 支持 | 暂不提供 | N, d |
| HK | 支持 | 暂不提供 | N, m, triad_probability |
| Chung–Lu | 支持 | 暂不提供 | w |

暂不提供的入口报 `graphgen:UnsupportedModelDirection`。原有随机定向包装与QS无向投影不再冒充该方向的原生模型。需要某篇论文的方向转换时，应另立有来源的转换协议。

## 来源固定与代码整理

NetworkX固定为 **3.5**。从GitHub该标签的API获取原始源码，记录Git blob SHA与SHA-256：[下载记录](../../sources/standard/networkx_3_5/manifest.json)。本机安装包的四个源文件已与下载文件逐字节校验一致。[BSD-3-Clause许可证](../../sources/standard/networkx_3_5/LICENSE.txt)保留在同目录。

| 接口 | 参考函数或原文 | 本次处理 |
|---|---|---|
| ER Gnp | `gnp_random_graph` | 对独立节点对作伯努利试验；逐行向量化 |
| ER Gnm | `gnm_random_graph` | 均匀无放回抽节点对编号，替代重复抽端点；输出均匀G(N,M) |
| BA | `barabasi_albert_graph` | 恢复默认m+1节点星形种子；从重复节点表中抽m个不同目标 |
| WS | `watts_strogatz_graph` | 保留环格、偏移优先遍历、单端重连；一次均匀抽合法目标 |
| NW | `newman_watts_strogatz_graph` | 恢复Graph.edges()的原边枚举顺序与源端机会 |
| SBM | `stochastic_block_model` | 固定分组、独立节点对；有向P无需对称 |
| RGG | `random_geometric_graph` | 单位立方体均匀坐标、欧氏距离阈值；去掉周期边界扩展 |
| 随机正则 | `random_regular_graph` | 替换有限换边法，保留stub洗牌、合法配对、余stub重试与整图重启 |
| HK | `powerlaw_cluster_graph` | 恢复m个孤立种子、预选目标集合、三角闭合、失败回退 |
| Chung–Lu | `expected_degree_graph(selfloops=False)` | 无自环独立边；按来源将大于1的乘积概率截为1 |
| SF | Goh, Kahng, Kim (2001), arXiv:cond-mat/0106565v2，第2–3页 | 按i^-sigma独立抽端点；有向分别使用出入权重；删掉offset扩展 |
| QS | Lou, Wang, Chen (2018), arXiv:1801.06082，单层构造 | 链骨架加r间隔独立回边，保持单层定义 |

[SF原文](https://arxiv.org/abs/cond-mat/0106565v2)、[QS原文](https://arxiv.org/abs/1801.06082)已下载并阅读相应构造段。论文文件及hash见[来源补充记录](../../sources/standard/source_notes.json)。SF、QS是按原文算法写的MATLAB实现，未声称从不存在的作者源码逐行移植。

BA/HK使用的Python整数集合迭代顺序会影响后续目标顺序。这里将所需的插入、扩容、遍历规则整理为MATLAB helper，固定 [CPython v3.13.7源文件](../../sources/standard/cpython_setobject.c)及[PSF许可证](../../sources/standard/CPYTHON_LICENSE.txt)，输入限定为不超过flintmax的正整数节点ID。只实现本场景需要的“插入后依次取出”，不实现通用Python集合。没有Python运行依赖。

## 保留的规则和来源边界

- **BA**：星形种子，M=m(N-m)，不是原版完全图种子的边数。每轮选目标时权重不变，选完再更新重复节点表。
- **HK**：开始是m个孤立点，重复节点表对这些点各保留一次初始权重。来源代码中三角闭合目标仍可能存在于预选集合，后续回退可重复添加这条边；简单图不增加重边，但计数和重复节点表照来源更新。本实现不暗中修正，`meta.duplicate_fallbacks`记录该次数，M=m(N-m)-duplicate_fallbacks。需要每步严格增加m条边的实验不要将该接口当作固定M模型。
- **NW**：原边按NetworkX的节点和邻居插入顺序遍历；无向边的源端不是每个节点固定K次机会。
- **随机正则**：`num_swaps`删除；不会从环格出发换边。来源的候选适合性检查与整图重试保留。其渐近均匀结论有度增长条件，不能写成任意有限N、d均严格均匀。高d可能需要较多重试，代码不自动改为其他生成器。
- **SF**：端点排名不偏移；有向允许互惠弧，M上限为N(N-1)。按来源一直拒绝重边/自环直至达到M，不用固定尝试上限筛掉难样本。高密度、极端权重可能慢。
- **WS/NW**：这里K对应NetworkX的k/2，限定1<=K<N/2。把“均匀抽节点并拒绝非法目标”改为“均匀抽合法目标”，条件分布相同；随机数消费数量不同。
- **ER Gnm**：每一步端点拒绝采样对所有剩余节点对等概率；均匀无放回编号采样具有同一集合分布。节点对反解只改变存储方式。
- **Chung–Lu**：p_ij=min(1,w_i*w_j/sum(w))，i不等于j；`expected_degree_no_loops`保存按实际截断规则算出的期望度。w不是强制的度序列。
- **RGG**：保留坐标到`meta.positions`；**SBM**保留分组到`meta.community`。I/O层将这些模型属性存入统一图文件。
- **QS**：只生成G_r(q,N)，不是所有r的并集。q控制回边概率，不固定M。

## 验证方法

[test_standard_models.m](../../validation/test_standard_models.m)检查16个支持入口、8个明确拒绝入口、RNG恢复、重复种子、边界图和来源决定的初始化。64组整数集合测试数据直接由Python生成，包括碰撞和多次扩容。

另用固定NetworkX源码独立计算四类模型各1024张小图的边数、度平方、三角形和首节点度；MATLAB各生成128张做均值诊断。生成诊断文件的脚本为[reference_oracle.py](../../sources/standard/reference_oracle.py)。诊断用于发现较大的移植偏差，不构成分布等价证明；同seed也不要求跨语言逐图相同。

主任务已执行MATLAB来源边界、集合样例与统计诊断；结果见[任务1验证](../validation/图生成历史验收记录_20260927.md)。

### 正则来源的适合性检查

NetworkX 3.5的`_suitable`内层交换会修改外层变量，可能在仍有可配点对时拒绝候选。例如已有边(0,1)、(0,2)，余stub节点顺序0、1、2，(1,2)可配而参考检查返回false。整理版保留这一行为，可能额外重启；不将引用论文的渐近结论当成对该具体实现的独立证明。配对重启没有确定时间上限，高密度应先用小样本计时。

ER-Gnm无向编号反解增加三角数区间校正，避免极大编号的平方根舍入造成自环；抽中的编号和抽样概率保持不变。边界测试只作标量运算。
