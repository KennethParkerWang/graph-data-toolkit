# 合成网络扩展模型与验证说明

2026-10-07，算法版本2.1.0新增7个命名模型和7个接口：6无向、1有向。模块合计 **23个命名模型、27个可用接口（17无向、10有向）**，另保留12个旧方向报错入口。具体参数顺序见[参数手册](../usage/图生成模型与参数手册.md)。已有NW、Chung–Lu参加本轮追加验证，二者不计入新增模型。

本页记录已实现的协议、来源差异和检查入口。公开版只携带源码和小型互操作夹具；完整历史运行报告与大规模图库不随代码上传。模型接入验证与正式图库、攻击标签和训练数据验收分别记录。

## 新增接口与结构覆盖

| 模型 | 方向 | 新增结构 | 精确保证与主要限制 |
|---|---|---|---|
| LFR | 无向 | 异质度、异质社区规模 | 社区分组和规模明确；目标度与目标mu不等于实际值 |
| 指定度序列 | 无向 | 固定逐节点度，改变连接方式 | 逐节点度精确；有限交换不保证均匀或混合充分 |
| DC-SBM | 无向 | 同一社区内度倾向不同 | Poisson多重图的存在性投影；原多图期望度不再精确保留 |
| Waxman-1 | 无向 | 随距离衰减的空间连接 | 使用实际欧氏距离；边数和连通性随机 |
| 复制—分化 | 无向 | 节点复制与连接保留 | 采用零边候选拒绝的连通版本；尝试预算可能失败 |
| RHG | 无向 | 双曲几何与温度连边 | 保存极坐标；不直接指定实际平均度 |
| Forest Fire | 有向 | 邻域燃烧的增长图 | 新节点只指向旧节点，是弱连通DAG |

所有接口返回稀疏logical简单图，不含自环和重边；保留N个节点。seed在最后，默认1；成功或失败均恢复调用者随机状态。不同随机流或不同实现版本不能要求与外部库同seed逐张相同。

<a id="lfr"></a>
## LFR：请求社区结构与实测结构分别记录

接口为 `gen_lfr_undirected(N,tau1,tau2,mu,average_degree,min_community,max_community,max_degree,max_iters,seed)`。`tau1,tau2>1`，`mu∈[0,1]`；社区规模和最大度界限均显式给出，详见[参数范围](../usage/图生成模型与参数手册.md#lfr)。

依据NetworkX 3.5 `LFR_benchmark_graph` 的离散幂律抽样、社区分配与逐节点配线流程。目标度序列须总度为偶数，社区规模须合计为N。内部目标为Python式偶数舍入的 `round(degree*(1-mu))`，本实现显式禁止自环。后续节点向先前节点连边会增加先前节点的度，所以成功结果的目标度是下界，不是逐节点精确约束。

| 请求或抽样目标 | 实际记录 |
|---|---|
| `parameters.average_degree` | `mean(meta.target_degrees)` 与 `meta.mean_degree` |
| `target_degrees` | `actual_degrees`、`degree_overshoot` |
| `parameters.mu` | `actual_mu_per_node`、`actual_mu_edge_fraction` |
| 社区上下限 | `community`、`community_sizes` |

逐节点实际mu为外部度/总度；本实现成功输出的目标度至少为1。边级实际mu为所有外部度之和/总度之和，即跨社区边占比。论文方法不得把请求mu直接作为实现后的测量值。

移植差异保存在 `parameters.source_differences`：有限截断Zipf的逆CDF抽样、MATLAB随机流、升序社区节点遍历、满社区移出最小节点、直接禁止自环、显式配线预算。没有声称与LFR作者二进制程序逐样本等价。

`max_iters`限制序列抽样；社区分配和配线各有 `10*N*max_iters` 尝试预算。最小度推导失败、社区合计失败、分配失败、合法邻居容量不足或配线超预算均明确报错。保持原seed和请求参数，失败信息用于重新设计参数，不能换seed凑齐成功图。

参考：[Lancichinetti、Fortunato、Radicchi，Benchmark graphs for testing community detection algorithms，PRE 78, 046110 (2008)](https://doi.org/10.1103/PhysRevE.78.046110)；[固定NetworkX 3.5参考源码](https://github.com/networkx/networkx/blob/networkx-3.5/networkx/generators/community.py)。

<a id="degree-sequence"></a>
## 指定度序列：精确度数与有限交换

接口为 `gen_degree_sequence_undirected(degrees,swap_attempts,seed)`。N由向量长度确定；输入每项为非负整数且小于N，总度为偶数，必须可图示。全零序列合法并保留全部孤立节点。

先以确定性的Havel–Hakimi算法构图：残余度相同按原节点编号升序处理。之后每次均匀选择两条不同边，并独立随机翻转端点方向；仅在四个端点互异且新边未存在时执行双边交换。始终保持逐节点度及 `M=sum(degrees)/2`，但连通分量可改变。

`swap_attempts` 是尝试预算，不是成功交换次数；不足两条边时实际尝试数为0。`meta.attempted_swaps`、`successful_swaps` 分别记录实际尝试和成功数。0次交换得到确定性的初始图。有限交换结果不保证均匀，不保证已经充分混合，也不等于Bayati随机度序列生成器。

保存 `target_degrees` 和 `actual_degrees`，验收应逐节点比较，不能只比较总边数。不图示、奇数总度或越界序列直接失败，不通过删除重边、补边或删孤立节点修改输入。

参考：[Hakimi，On Realizability of a Set of Integers as Degrees of the Vertices of a Linear Graph. I，SIAM J. Appl. Math. 10:496–506 (1962)](https://doi.org/10.1137/0110037)，并保留Havel (1955)归属；简单图交换条件参照[NetworkX 3.5 double_edge_swap](https://github.com/networkx/networkx/blob/networkx-3.5/networkx/algorithms/swap.py)，初始构图和有限尝试协议由本项目独立实现。

<a id="dc-sbm"></a>
## DC-SBM：明确标记简单图投影

接口为 `gen_dc_sbm_undirected(sizes,theta,omega,seed)`。社区按连续编号分组；每组theta总和为1，允许theta为0。omega是非负、有限、严格对称的社区强度矩阵，不能把它当作SBM的概率矩阵直接使用。

原模型不同节点对的边重数服从Poisson分布，均值 `lambda_ij=theta_i*theta_j*omega_rs`。本接口仅保存边是否存在，因此 `p_ij=1-exp(-lambda_ij)`；使用 `-expm1(-lambda_ij)` 避免微小强度被相减消去。自环直接排除，互异节点对独立抽样。theta为0的节点始终保留且孤立，不强制连通。

输入theta是组内连接倾向，不是实际度。原Poisson多图的度期望不能直接用于该简单图；准确简单图期望度为 `sum_{j!=i} p_ij`，保存在 `parameters.expected_degree_simple_no_loops`。`original_poisson_expected_degree_is_preserved=false` 和构造字段记录此差异。

参考：[Karrer与Newman，Stochastic blockmodels and community structure in networks，PRE 83, 016107 (2011)，式14–15](https://doi.org/10.1103/PhysRevE.83.016107)。按论文规则自主实现，未拷入外部生成器代码。

<a id="waxman"></a>
## Waxman-1：使用本张图的真实距离

接口为 `gen_waxman_undirected(N,alpha,beta,seed)`。alpha为有限正数，beta在 `[0,1]`。N个节点独立均匀分布于单位正方形，L取所有节点对的最大欧氏距离；每个节点对以 `beta*exp(-d/(alpha*L))` 独立连边。

只实现NetworkX `L=None` 的Waxman-1。Waxman-2会将成对距离替换为独立随机数，本项目未采用该规则。`meta.positions`、`parameters.L` 和 `parameters.variant='waxman_1'` 用于检查实际几何。

beta为0得到空边图；N=1保留单个节点且L=0。若全部坐标重合，零距离节点对的概率约定为beta。固定alpha/beta不会固定M，也不会保证连通。空间位置和边概率必须按保存的本张图坐标计算。

参考：[Waxman，Routing of multipoint connections，IEEE JSAC 6(9):1617–1622 (1988)](https://doi.org/10.1109/49.12889)；[NetworkX 3.5几何生成器](https://github.com/networkx/networkx/blob/networkx-3.5/networkx/generators/geometric.py)。

<a id="duplication-divergence"></a>
## 复制—分化：连通版本与尝试预算

接口为 `gen_duplication_divergence_undirected(N,p,max_attempts,seed)`；预算位于seed之前。N至少2，p在 `(0,1]`；预算缺省或 `[]` 时为 `max(10000,100*N)`。

从两节点一条边开始；每次均匀抽一个旧节点，复制其邻居，并逐条独立以p保留复制连接。候选若未保留任何边就拒绝，N不增加。旧边不被删除，也不会自动连到被复制的源节点。成功图因该生成条件保持连通。

采用NetworkX 3.5 `duplication_divergence_graph` 的连通版本，不是允许断连的 `partial_duplication_graph`。本项目额外拒绝p=0，避免参考实现在需要增长时陷入不终止循环；全局预算耗尽时报 `graphgen:DuplicationAttemptLimit`，不改p、不更换seed。N=2不需复制，允许预算为0。

`duplication_parent` 保留每个成功节点的复制源；`duplication_attempts` 与 `rejected_duplications` 记录尝试和拒绝数量。p=1时得到由复制孪生节点增长的完全二部图，可作为独立结构检验。

参考：[Ispolatov、Krapivsky、Yuryev，Duplication-divergence model of protein interaction network，PRE 71, 061911 (2005)](https://doi.org/10.1103/PhysRevE.71.061911)；[固定NetworkX 3.5复制生成器](https://github.com/networkx/networkx/blob/networkx-3.5/networkx/generators/duplication.py)。

<a id="rhg"></a>
## RHG：双曲距离与有限温度

接口为 `gen_rhg_undirected(N,R,alpha,T,seed)`。曲率固定−1，角度在 `[0,2*pi)` 均匀抽样；半径累计分布为 `(cosh(alpha*r)-1)/(cosh(alpha*R)-1)`。T=0时按双曲距离 `d≤R` 连边；T>0时概率为 `1/(1+exp((d-R)/(2*T)))`。

实现采用稳定的半双曲函数距离公式与逻辑概率计算；数值范围为 `0≤R≤350`、`alpha>0`、`alpha*R≤700`、`T≥0`，超界直接失败。R=0时位置全部重合：T=0完全连边，T>0节点对概率1/2。N=1保留单节点，不含自环。

`meta.r` 与 `angles` 保存极坐标；R、alpha、T控制结构分布，不能把输入R直接写成实际平均度，也不能保证每张有限图满足某个幂律或聚类水平。不按连通性、平均度或其他测量结果筛选。

参考：[Krioukov等，Hyperbolic Geometry of Complex Networks，PRE 82, 036106 (2010)](https://arxiv.org/abs/1006.5169)，式5、17、41；按论文规则自主实现，未拷入外部代码。

<a id="forest-fire"></a>
## Forest Fire：SNAP零起点几何与原生DAG

接口为 `gen_forest_fire_directed(N,p_forward,p_backward,seed)`；两个概率均在 `[0,1)`。初始一个节点，新节点均匀选一个旧节点作为燃烧起点。按广度优先顺序，对每个燃烧节点先处理出邻居、后处理入邻居；均匀无放回选择尚未访问的邻居，各节点在一轮内只访问一次。新节点向烧到的所有旧节点连弧。

几何燃烧数采用作者SNAP的零起点约定：`Pr(K=k)=(1-p)*p^k`，k从0开始，未按合法邻居容量截断前的均值为 `p/(1-p)`。实际燃烧数受可用邻居数限制。KDD05部分文字中的正起点几何均值与该约定不同，不能宣称逐字采用其所有表述。

论文的后向比例r在 `p_forward>0` 时对应 `p_backward=r*p_forward`；若前向概率为0，则该比值未定义，但双概率接口仍合法，元数据明确标记。两个概率均为0时，每个新节点只连向起点，得到N−1条弧的有向递归树。

弧总是从较新编号指向较旧编号，因此图为DAG，无互惠修补。N>1时保证弱连通，不能用作强连通有向网络；N=1时保留一个节点。`meta.ambassadors` 保存各新节点的起点，几何支持集、概率质量函数、名义均值和遍历顺序也记录在元数据中。

参考：[Leskovec、Kleinberg、Faloutsos，Graphs over Time: Densification Laws, Shrinking Diameters and Possible Explanations，KDD 2005，§4.2.1](https://www-cs.stanford.edu/~jure/pubs/powergrowth-kdd05.pdf)；[固定SNAP版本BurnGeoFire规则核对](https://github.com/snap-stanford/snap/blob/6924a035aabd1ce0a547b94e995e142f29eb5040/snap-core/ff.cpp)。本项目依据规则自主实现；SNAP只用于约定核对，未将其代码抄入项目。
