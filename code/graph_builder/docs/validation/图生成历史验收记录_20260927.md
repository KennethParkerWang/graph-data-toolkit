## 修复与验证边界

初次集成遇到测试无法访问MATLAB private函数，已把共享整数集合helper移到common并增加输入检查；另一次运行命令误接收无返回值的test_graph_io输出，已改正调用方式。最终统一入口完整通过；早期失败日志保留用于定位，不作为当前失败状态。

审查修复了正式索引与part冲突漏检、Java相对路径、存档配置移动后的output_dir和续跑RNG算法校验。批量生成一次计算实现指纹，并按生成器缓存来源文件摘要，避免每张图重读参考论文及源码。

统计诊断用于发现较大偏移，不证明所有规模下的分布等价。没有对本版作大规模性能压测；旧1.x性能倍数不能沿用。标准高密度SF/正则可能长时间拒绝或重启；作者模型的工作量上限只产生明确失败，不另造图。

作者参考包中部分程序会产生非法简单图或直接报错，这些是已复核的来源边界；12个缺乏独立来源的方向入口明确拒绝。首次初始化在dataset.json发布前中断会拒绝接管残留目录，图生成尚未开始。

极大编号的平方根舍入问题已修复：保留原均匀抽样，仅按三角数区间校正节点对反解。N=120000001、rank=7199999940000001这一反例现在得到(1,120000001)，不会生成错误自环。批量预检同时拒绝节点对总数超过flintmax的ER-Gnm请求。
