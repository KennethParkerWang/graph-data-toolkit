# 批量图生成与任务存储

入口为`generate_graph_batch(config_file,'DryRun',true)`。配置格式为2，输出格式为graph-v1。只生成原始图，指标和攻击结果另存。

## 配置示例

以下配置保存在`code/graph_builder/configs/example.json`时，输出到项目的`datasets/example`：

```json
{
  "schema_version": 2,
  "dataset_id": "example",
  "output_dir": "../../../datasets/example",
  "base_seed": 20260927,
  "samples_per_combination": 3,
  "resume": true,
  "on_error": "continue",
  "max_graphs": 10000,
  "jobs": [
    {
      "model": "ws",
      "direction": "undirected",
      "parameters": {"K": 4},
      "grid": {
        "N": [100, 300, 500],
        "beta": {"start": 0, "stop": 0.2, "step": 0.1}
      }
    }
  ]
}
```

3个N、3个beta、每组3张，共27张。`output_dir`相对配置文件所在目录解析，与MATLAB当前目录无关。`dataset_id`以英文字母开头，仅使用字母、数字、下划线、连字符。

`parameters`设置固定参数，`grid`覆盖其中的同名标量。列表与`start/stop/step`均支持；不执行字符串表达式。网格字段按名称排序，第一个字段变化最快。`sizes/P/w`是一个完整向量或矩阵，不放入grid；不同向量值分别写job。

`seed=base_seed+sample_id-1`，sample_id为从1开始的全局计划序号。默认每组合1张；job的`samples`覆盖全局`samples_per_combination`。参数默认值展开后存入计划，完整实际参数另存图文件。改变job顺序会改变seed分配。

| 字段 | 默认值/规则 |
|---|---|
| schema_version | 必填，2 |
| dataset_id、output_dir、base_seed、jobs | 必填 |
| samples_per_combination | 1 |
| resume | true；false拒绝已有数据集 |
| on_error | continue；也可用stop |
| max_graphs | 10000，预览展开的数量上限 |

## 执行

```matlab
cd('code/graph_builder');
setup_generators;
plan = generate_graph_batch('configs/smoke.json','DryRun',true);
disp(plan.plan);
result = generate_graph_batch('configs/smoke.json');
```

预览只展开参数、验证静态可行域，不写目录也不调用随机生成。有限参数约束可提前拒绝；作者源码异常、随机拒绝耗时、存储空间等运行时问题不能靠预览保证。

生成器按样本串行执行。`result`含planned/generated/skipped/recovered/failed、plan、output_dir、run_log、records。事件日志保留实际N/M、seed、展开参数、错误及耗时；若未生成有效图，graph_id/path为空。`on_error=stop`仍先记录失败再终止；continue继续下一计划样本，绝不自动换seed补数量。

## 输出与续跑

- `dataset.json`记录规范、实现、配置摘要和相对索引路径。
- `configs/generation.json`是可直接重跑的完整快照，内部output_dir为`..`。
- `graphs/<prefix>/<graph_id>.mat`只保存原图。
- `manifests/parts/`保存不可变图登记分片，`graphs.jsonl`由单个合并器验证后原子发布。
- `manifests/generation_runs/`每次调用新建独立JSONL，保留失败历史。

重跑先比较配置身份及当前算法源码摘要，再核对历史事件与当前计划。已完成图同时核验part、正式索引、文件bytes/hash、规范字段、图身份、参数、种子及RNG算法。不改写已有MAT；损坏或冲突明确失败。上次图已保存但登记中断时，只有科学内容与重新生成候选一致才补登记，返回recovered。

配置身份排除output_dir、resume、on_error、max_graphs；它们不改变生成配方。修改模型、参数、seed或算法源码需使用新数据集。移动整个数据集后可直接运行新位置的`configs/generation.json`，ID和索引路径不变。

同一数据集只允许一个批量调度进程，`.graphgen.lock`由原子mkdir获取。底层I/O另有单图锁、独立part和合并锁，可供后续显式分片调度使用。强行结束进程可能遗留锁，须确认无运行写入者后再处理该精确锁目录，不能盲删。

若首次初始化在dataset.json发布前中断，入口拒绝接管非空目录。此时尚未开始生成图；检查残留的configs目录后选择新的输出目录。已正式初始化的数据集支持上述图文件恢复规则。

## 参数选择

```matlab
make_pilot_config('configs/my_pilot.json', [100 300 500], [4 8 12], 5, 20260927);
```

它生成27组参数、135张图的配置，不运行图生成，也不覆盖已有配置文件。ER-Gnm取M=N*k/2；WS取K=k/2；BA取m=k/2，但星形种子使实际平均度为2*m*(N-m)/N。这里的k是匹配稀疏程度的目标，不保证三个模型实际度完全一样。

当前K按每侧邻居数解释；SF不再有offset；RGG不再有periodic；正则图不再有num_swaps。各模型可用方向和完整范围以[模型手册](图生成模型与参数手册.md)及registry为准。
