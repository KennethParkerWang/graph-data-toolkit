# 图生成模型与参数手册

本手册对应 **2.1.0**：23个命名模型、27个可用接口（无向17个、有向10个）。另12个旧方向入口只返回“不支持”错误；公共生成入口共39个。原有来源见[标准模型](../models/标准图模型与来源说明.md)、[作者 EH/多边形模型](../models/作者图模型与已知边界.md)，新增7个模型见[扩展模型与验证说明](../models/合成网络扩展模型与验证说明.md)。旧 `model_source_audit.md` 记录的是1.1.0，不作为当前接口说明。

## 调用与输出

```matlab
cd('code/graph_builder');
setup_generators;
[A, meta] = gen_er_gnm_undirected(100, 300, 1);
```

所有可用函数返回 `N×N` 稀疏 `logical` 邻接矩阵 `A` 和元数据 `meta`。保留孤立节点，无自环；无向矩阵对称，有向 `A(i,j)=1` 表示 `i→j`。

| 量 | 无向 | 有向 |
|---|---|---|
| `meta.num_edges` | `nnz(A)/2` | `nnz(A)`，即弧数 |
| `meta.mean_degree` | `2M/N` | 平均总度 `2M/N` |
| `meta.mean_in_degree` / `mean_out_degree` | 不提供 | 各为 `M/N` |

`seed` 均在最后，省略时固定为 1；范围为整数 `0…2^32-1`。调用恢复外部随机状态。批量生成必须显式变更种子；不同种子不保证拓扑不同。固定种子只保证同一实现版本内复现，不要求与 Python 的同种子图逐一相同。

下表中 `N、M、m、K、r、d、dim` 都是整数。除特别说明外，模型参数必须显式提供；SF指数默认0.5、RGG的 `dim` 默认2、复制—分化的 `max_attempts` 默认 `max(10000,100*N)`、各函数 `seed` 默认1。不要省略中间参数后把seed放错位置，复制—分化如需默认预算且指定seed，应传 `[]` 占位。

图文件统一由 [I/O 层](../../io/README.md)写入；数据集目录、类型和 ID 见[图存储规范](../graph_schema_v1.md)。指标单独保存，不修改原始图。

| RT / RR / RH | 不提供 | 作者实现 | 成功时精确 M |
| SBM | 支持 | 支持 | 随机 |

| LFR社区网络 | 支持 | 不提供 | 随机，目标度与实际度分别记录 |
| 指定度序列 | 支持 | 不提供 | 精确 `sum(degrees)/2` |

上述12个方向有保留的报错入口；新增模型只提供表中方向，没有为其增加相反方向的包装函数。

<a id="er-p"></a>
## ER-p：独立概率随机图

**接口：** `gen_er_undirected(N,p,seed)`、`gen_er_directed(N,p,seed)`。

`N≥1`，`0≤p≤1`。无向对每个 `i<j` 独立以 p 连边；有向对每个 `i≠j` 独立以 p 生成弧，允许互惠弧。无向 `E[M]=pN(N-1)/2`；有向 `E[M]=pN(N-1)`。不筛选连通图。

```matlab
[A, meta] = gen_er_undirected(100, 0.06, 1);
[D, meta_d] = gen_er_directed(100, 0.03, 1);
```

来源：NetworkX 3.5 `gnp_random_graph` 的独立边模型；本实现按行生成伯努利变量。

<a id="er-m"></a>
## ER-m：固定边数随机图

**接口：** `gen_er_gnm_undirected(N,M,seed)`、`gen_er_gnm_directed(N,M,seed)`。

`N≥1`，`M≥0`。无向 `M≤N(N-1)/2`；有向 `M≤N(N-1)`。节点对总数还须不超过flintmax，以保证编号精确。从全部合法节点对中均匀无放回抽取 M 对；有向允许互惠弧。适合需要精确控制 N、M 的随机基线。

```matlab
[A, meta] = gen_er_gnm_undirected(100, 300, 1);
[D, meta_d] = gen_er_gnm_directed(100, 300, 1);
```

来源：NetworkX 3.5 `gnm_random_graph`。无放回编号采样与重复抽端点并拒绝非法边有相同集合分布，但随机数消费不同。

<a id="ba"></a>
## BA：增长与优先连接

**接口：** `gen_ba_undirected(N,m,seed)`。

`N≥2`，`1≤m<N`。从 `m+1` 个节点的**星形图**开始；每个新节点按度权重选择 m 个不同旧节点。当前一轮目标全部选完后才更新权重表。边数为 `M=m(N-m)`，平均度为 `2m(1-m/N)`；结果连通。

```matlab
[A, meta] = gen_ba_undirected(100, 3, 1);
```

来源：NetworkX 3.5 `barabasi_albert_graph` 默认初始化。不是旧版完全图种子；论文方法应写明星形种子。

<a id="sf"></a>
## 静态 SF：按排名权重抽边

**接口：** 无向 `gen_sf_undirected(N,M,sigma,seed)`；有向 `gen_sf_directed(N,M,sigma_out,sigma_in,seed)`。

`N≥1`，各指数在 `[0,1)`，默认均为 0.5。M 的上限与对应方向 ER-m 相同。无向端点独立按 `i^(-sigma)` 抽取；有向源、目标分别按 `i^(-sigma_out)`、`j^(-sigma_in)` 抽取。拒绝自环和已存在边，直到接收 M 条。原生有向版本允许互惠弧。

```matlab
[A, meta] = gen_sf_undirected(100, 300, 0.5, 1);
[D, meta_d] = gen_sf_directed(100, 300, 0.4, 0.7, 1);
```

来源：Goh、Kahng、Kim，DOI `10.1103/PhysRevLett.87.278701`，原始静态无向/有向构造。没有 offset 参数、连通筛选或固定拒绝预算。接近容量上限、指数很大时重复抽样可能很慢；模型名称不保证每张有限图通过幂律检验。

<a id="ws"></a>
## WS：环格重连

**接口：** `gen_ws_undirected(N,K,beta,seed)`。

`N≥3`，`1≤K<N/2`，`0≤beta≤1`。K 是**每侧邻居数**，对应 NetworkX 参数 `k=2K`。先建环格，按偏移、源节点顺序遍历原边；以 beta 重连目标，从当前合法非邻居中均匀选择。没有候选时保留原边。始终 `M=NK`，重连后可能不连通。

```matlab
[A, meta] = gen_ws_undirected(100, 3, 0.1, 1);
```

来源：NetworkX 3.5 `watts_strogatz_graph`。beta=0 是环格；beta=1 不等于均匀 ER。

<a id="nw"></a>
## NW：环格增加捷径

**接口：** `gen_nw_undirected(N,K,beta,seed)`。

参数范围同 WS。保留全部环格边；按 NetworkX 的原边枚举顺序，每条原边做一次 beta 试验，从该边源节点向合法非邻居加捷径。成功输出 `M=NK+meta.shortcut_edges`，保留连通性。每个节点获得的试验次数不是固定 K。

```matlab
[A, meta] = gen_nw_undirected(100, 3, 0.1, 1);
```

来源：NetworkX 3.5 `newman_watts_strogatz_graph`。边数由实际成功捷径决定；高密度时不能把 `NK(1+beta)` 当精确期望。

<a id="eh"></a>
## EH：有向随机边整流

**接口：** `gen_eh_directed(N,M,seed)`。

`N≥1`，`0≤M≤N(N-1)`。先按作者 `ern.m` 生成原生有向固定 M 随机图，再按 `rectify.m` 的四类整流操作处理。成功时入度、出度分别落在 `floor(M/N)…ceil(M/N)`，允许互惠弧，不保证连通。

```matlab
[D, meta] = gen_eh_directed(20, 60, 2);
```

来源：作者 `enc_ver1.zip`（2020-04-29），DOI `10.1109/TCSI.2020.2986215`。原版部分种子返回自环；本实现完整保留随机轨迹，最终仍有自环时报错，不随机补图。示例种子已和原版对照；其他种子需要保留失败记录。详见[来源缺陷和确定性复现](../models/作者图模型与已知边界.md)。

<a id="qs"></a>
## QS：单 r 层 q-snapback

**接口：** `gen_qs_directed(N,r,q,seed)`。

`N≥2`，`1≤r<N`，`0≤q≤1`。先建 `1→2→…→N`；对每个 `i=r+1…N`，给候选 `i→i-lr` 独立以 q 加边，`l=1…floor((i-1)/r)`。结果保证弱连通，不强制强连通；r=1 可以有互惠弧。

若 `C=sum(floor((1:N-1)/r))`，则 `E[M]=N-1+qC`。q 是各候选回边的概率，不是固定边删除/增加比例。

```matlab
[D, meta] = gen_qs_directed(100, 2, 0.05, 1);
```

来源：Lou、Wang、Chen，DOI `10.1109/TCSI.2018.2821124` 的 `G_r(q,N)`。此接口只有单 r 层，没有合并全部层。

<a id="polygon-rules"></a>
## RT / RR / RH：作者 Henneberg 增长图

有向简单图接口如下，M 均为 `0…N(N-1)/2`，成功结果无互惠弧。不再添加自行规定的 N 同余条件。

| 模型 | 参数范围 | 示例 |
|---|---|---|
| <a id="rt"></a>RT 三角形 | `N≥3` | `gen_rt_directed(30,57,1)` |
| <a id="rr"></a>RR 矩形 | `N≥5` | `gen_rr_directed(29,41,1)` |
| <a id="rh"></a>RH 六边形 | `N≥7` | `gen_rh_directed(30,36,1)` |

从作者规定的有向环开始。增长时先均匀抽一个旧节点，再均匀抽其出/入邻居；保持该锚弧并接入新的返回路径。RR/RH 保留作者的截断和尾部补环。增密与删边也分别遵循各自原代码，不统一替换成均匀抽边。尾删边可能破坏连通性。

来源：作者 `hg.zip`（2021-12-12）中的 `rt.m`、`rr.m`、`rh.m`，DOI `10.1109/ACCESS.2022.3141011`。原版存在空邻居、自环和互惠弧路径；静态合法参数不保证每个种子成功。原版失败和非法最终图明确记录，不修补、不偷偷换种子。拒绝/整流有工作量上限，到限只报失败。验证和边界见[作者模型说明](../models/作者图模型与已知边界.md)。

<a id="sbm"></a>
## SBM：固定分组独立边

**接口：** `gen_sbm_undirected(sizes,P,seed)`、`gen_sbm_directed(sizes,P,seed)`。

`sizes` 是非空正整数向量，`N=sum(sizes)`。若有 B 个组，P 必须为 `B×B`，元素在 `[0,1]`；无向要求严格对称，有向可以不对称。每个合法节点对独立抽样，概率由所属组给定。连续节点编号对应连续社区；`meta.community` 保存分组。

```matlab
[A, meta] = gen_sbm_undirected([50,50], [0.12,0.01;0.01,0.12], 1);
[D, meta_d] = gen_sbm_directed([50,50], [0.10,0.03;0.01,0.10], 1);
```

来源：NetworkX 3.5 `stochastic_block_model`。这是概率型 SBM，不固定块间边数，也不是度修正 SBM；是否存在明显社区取决于 P。

<a id="rgg"></a>
## RGG：随机几何图

**接口：** `gen_rgg_undirected(N,radius,dim,seed)`。

`N≥1`，`radius≥0`，`dim≥1`（默认2）。节点独立均匀分布于单位 dim 维立方体；欧氏距离不超过 radius 时连边。使用开放边界，没有 periodic 参数。`meta.positions` 保存 `N×dim` 坐标，统一存储时不能丢弃。

```matlab
[A, meta] = gen_rgg_undirected(100, 0.15, 2, 1);
```

来源：NetworkX 3.5 `random_geometric_graph`，欧氏距离。固定半径不保证固定平均度或连通；边界会影响距离分布。

<a id="regular"></a>
## 随机正则图

**接口：** `gen_random_regular_undirected(N,d,seed)`。

`N≥1`，`0≤d<N`，`Nd` 必须为偶数。将节点 stub 洗牌配对，保留合法边，对余下 stub 重新配对；参考适合性检查拒绝剩余配对时重新生成整张候选图。每个节点的度精确为 d，`M=Nd/2`。不含 `num_swaps` 参数，也不从环格开始换边。

```matlab
[A, meta] = gen_random_regular_undirected(100, 6, 1);
```

来源：NetworkX 3.5 `random_regular_graph` 的配对/重启算法。相关均匀性结论有渐近和度增长条件，不能表述为所有有限 N、d 下严格均匀。该具体参考检查可能过早拒绝仍可配对的候选，整理版保留其行为；高 d 可能多次重启，没有确定时间上限。代码不自动换算法，不强制连通。详见[来源限定](../models/标准图模型与来源说明.md)。

<a id="hk"></a>
## HK：优先连接与三角闭合

**接口：** `gen_hk_undirected(N,m,triad_probability,seed)`。

`N≥1`，`1≤m≤N`，`0≤triad_probability≤1`。从 m 个孤立节点开始，先按重复权重表选目标集合；每个新节点先做优先连接，再尝试三角闭合，不能闭合时回退到预选目标。保留来源的目标集合更新顺序。

```matlab
[A, meta] = gen_hk_undirected(100, 3, 0.4, 1);
```

来源：NetworkX 3.5 `powerlaw_cluster_graph`。来源代码的回退可能重复连接已经通过三角闭合连过的目标，简单图不增加重复边，但内部计数仍更新；因此 `M=m(N-m)-meta.duplicate_fallbacks`。不能把该接口当作固定 M 模型。m=N 时没有增长，输出 N 个孤立节点。`triad_probability` 不是实际聚类系数。

<a id="chung-lu"></a>
## Chung–Lu：期望度权重

**接口：** `gen_chung_lu_undirected(w,seed)`。

w 为非空有限非负向量，且总和有限，`N=numel(w)`。对 `i<j` 独立按 `p_ij=min(1,w_i*w_j/sum(w))` 连边；总权重为零时为空图。没有自环，不强制每个节点的实际度等于 w。

```matlab
[A, meta] = gen_chung_lu_undirected([2*ones(50,1);8*ones(50,1)], 1);
```

来源：NetworkX 3.5 `expected_degree_graph(selfloops=False)`。概率超1时按来源截为1；去自环和截断都会影响期望度。按实际概率计算的期望度保存在 `meta.parameters.expected_degree_no_loops`。

<a id="lfr"></a>
## LFR：度与社区规模异质性

**接口：** `gen_lfr_undirected(N,tau1,tau2,mu,average_degree,min_community,max_community,max_degree,max_iters,seed)`。

`N≥2`，`tau1,tau2>1`，`0≤mu≤1`，`1≤average_degree≤max_degree<N`。社区上下限为整数且 `1≤min_community≤max_community≤N`；`max_degree,max_iters` 也是整数，`max_iters≥1`。除seed外均无默认值。

NetworkX 3.5离散幂律配线流程的简单图移植；没有自环，不强制连通。`average_degree` 与 `mu` 是请求参数，实际度可能超过抽到的目标度，实际混合比例也可能偏离请求值。应读取 `meta.target_degrees`、`actual_degrees`、`degree_overshoot`、`actual_mu_per_node` 和 `actual_mu_edge_fraction`。

```matlab
[A, meta] = gen_lfr_undirected(400,2.5,1.5,0.2,8,20,80,50,1000,38);
```

抽样预算、遍历差异、失败条件及[LFR原始论文](https://doi.org/10.1103/PhysRevE.78.046110)见[扩展说明](../models/合成网络扩展模型与验证说明.md#lfr)。

<a id="degree-sequence"></a>
## 指定度序列：精确保持每个节点的度

**接口：** `gen_degree_sequence_undirected(degrees,swap_attempts,seed)`。

`degrees` 是非空非负整数向量，`N=numel(degrees)`，每项小于N，总度为偶数且序列可图示；`swap_attempts` 为非负整数。先按确定性的Havel–Hakimi规则构图，再尝试指定次数的随机双边交换。逐节点实际度精确等于输入，`M=sum(degrees)/2`，不强制连通。

```matlab
[A, meta] = gen_degree_sequence_undirected(8*ones(400,1),10000,41);
```

这是有限交换方案，不保证均匀采样，也不是NetworkX的Bayati随机度序列算法。交换请求次数、实际尝试和成功数分开记录；详见[扩展说明](../models/合成网络扩展模型与验证说明.md#degree-sequence)。

<a id="dc-sbm"></a>
## DC-SBM：度倾向与社区结构

**接口：** `gen_dc_sbm_undirected(sizes,theta,omega,seed)`。

`sizes` 为非空正整数社区规模向量；`theta` 长度为N，每项在 `[0,1]`，每组总和须在绝对误差 `1e-12` 内等于1。`omega` 是有限、非负、严格对称的社区强度矩阵。不同 `i<j` 以 `1-exp(-theta_i*theta_j*omega_rs)` 独立连边，使用 `expm1` 处理微小强度。

```matlab
[A, meta] = gen_dc_sbm_undirected([200,200],ones(400,1)/200,[1800,200;200,1800],61);
```

采用[Karrer–Newman原模型](https://doi.org/10.1103/PhysRevE.83.016107)的Poisson多重边存在性投影并去自环；原多图的期望度不再精确保留。简单图准确期望度为 `meta.parameters.expected_degree_simple_no_loops`。`theta=0` 的节点保持孤立；不强制连通。

<a id="waxman"></a>
## Waxman-1：按空间距离抽边

**接口：** `gen_waxman_undirected(N,alpha,beta,seed)`。

`N≥1`，有限 `alpha>0`，`0≤beta≤1`。节点独立均匀分布于单位正方形，L取本张图所有节点对的最大欧氏距离；按 `beta*exp(-d/(alpha*L))` 连边。`meta.positions` 保留坐标，`meta.parameters.L` 保存L。

```matlab
[A, meta] = gen_waxman_undirected(400,0.3,0.08,62);
```

只实现[Waxman-1](https://doi.org/10.1109/49.12889)；没有Waxman-2的独立随机距离替换。`beta=0` 为空图；`N=1` 时保留单节点且L=0。若全部坐标重合，零距离节点对的概率定义为beta。边数随机，不强制连通。

<a id="duplication-divergence"></a>
## 复制—分化：保留部分复制连接

**接口：** `gen_duplication_divergence_undirected(N,p,max_attempts,seed)`。

`N≥2`，`0<p≤1`；`max_attempts` 是非负整数，缺省或 `[]` 时为 `max(10000,100*N)`。从两节点一条边开始，均匀选择旧节点，复制其邻居并逐边以p保留；零边候选被拒绝，不增加节点数。成功结果连通。

```matlab
[A, meta] = gen_duplication_divergence_undirected(400,0.55,[],63);
```

使用[复制—分化论文](https://doi.org/10.1103/PhysRevE.71.061911)对应的NetworkX 3.5连通版本。显式拒绝p=0；达到全局尝试预算时报错，不改seed或p。N=2无需复制，允许零预算。父节点、尝试数和拒绝数分别保存在 `duplication_parent`、`duplication_attempts`、`rejected_duplications`。

<a id="rhg"></a>
## RHG：随机双曲图

**接口：** `gen_rhg_undirected(N,R,alpha,T,seed)`。

`N≥1`，`0≤R≤350`，`alpha>0`，`alpha*R≤700`，`T≥0`。曲率固定为−1；角度均匀，半径按 `(cosh(alpha*r)-1)/(cosh(alpha*R)-1)` 的累积分布抽样。T=0时，双曲距离不超过R的节点对连边；T>0时按逻辑概率 `1/(1+exp((d-R)/(2*T)))` 独立连边。

```matlab
[A, meta] = gen_rhg_undirected(400,12,0.75,0.5,51);
```

依据[Krioukov等人的双曲几何模型](https://arxiv.org/abs/1006.5169)。R不直接固定平均度；实际度和边数必须另记。`meta.r`、`angles` 保存坐标。R=0时圆盘收缩为一点：T=0输出完全图，T>0每对连边概率为1/2；N=1始终保留单个孤立节点。不强制连通。

<a id="forest-fire"></a>
## Forest Fire：有向森林火灾增长

**接口：** `gen_forest_fire_directed(N,p_forward,p_backward,seed)`。

`N≥1`，两个概率均在 `[0,1)`。每个新节点均匀选择一个旧节点作起点，按广度优先顺序先前向、后后向燃烧旧图邻居，无放回选邻居且不重复访问；新节点仅向烧到的旧节点连弧。结果为弱连通DAG，N>1时不可能强连通。

```matlab
[D, meta] = gen_forest_fire_directed(400,0.35,0.2,52);
```

依据[KDD 2005论文](https://www-cs.stanford.edu/~jure/pubs/powergrowth-kdd05.pdf)，燃烧数采用作者SNAP的零起点几何约定：`Pr(K=k)=(1-p)*p^k`，未按可用邻居数截断前的均值为 `p/(1-p)`。这与论文部分文字的正起点均值约定有区别，详见[扩展说明](../models/合成网络扩展模型与验证说明.md#forest-fire)。双概率为0时是 `N-1` 弧的递归树；N=1时为空边单节点图。

<a id="degree-guide"></a>
## 从规模和平均度选参数

| 目标 | 参数关系 | 注意事项 |
|---|---|---|
| 无向精确平均度 k | `M=Nk/2`，用于 ER-m/SF | M 必须整数且不超容量 |
| 有向精确平均出度 k_out | `M=N*k_out` | 总平均度是 `2*k_out` |
| 无向 ER-p 期望平均度 k | `p=k/(N-1)` | 单张图的 M 随机 |
| 有向 ER-p 期望出度 k_out | `p=k_out/(N-1)` | 单张图的 M 随机 |
| WS 平均度 k | `K=k/2` | k 是偶整数，`K<N/2` |
| BA 平均度 | `k=2m(1-m/N)` | `m≈k/2` 只是大 N 近似 |
| 随机正则平均度 k | `d=k` | d 整数，Nd 偶数 |
| EH 平均入/出度 | `M/N` | 边数不自动决定每个种子成功 |
| HK / NW / RGG / SBM / Chung–Lu | 用实际 `meta.num_edges` 核查 | 不要将概率/权重误写成固定 M |
| 指定度序列平均度 k | `mean(degrees)=k` | 序列必须可图示；交换不改变度数 |
| LFR / DC-SBM / Waxman / 复制—分化 / RHG / Forest Fire | 保存请求参数及实际 N/M/度 | 这些接口的参数不统一等同于实际平均度 |

批量范围与配置见[批量生成说明](批量图生成与任务存储.md)。N 与 M 往往需要联动；若想控制平均度，不应盲目对 N、M 做独立笛卡尔积。先用小批样本检查实际规模、失败记录、生成时间和存储大小，再确定正式参数组合。
