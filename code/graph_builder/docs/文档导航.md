# 图生成文档导航

本模块负责生成、校验和保存原始图。先查使用接口，再按需查模型来源与验证记录。

## 建议阅读顺序

1. 读[图生成模型与参数手册](usage/图生成模型与参数手册.md)，选择模型、方向和参数。
2. 读[批量图生成与任务存储](usage/批量图生成与任务存储.md)，准备批量配置和运行目录。
3. 读[原始图存储规范 v1](graph_schema_v1.md)及[原始图交接与读写示例](usage/原始图交接与读写示例.md)，确认保存格式和下游读取方式。
4. 需要核对算法依据或过往验收时，再读模型来源和验证记录。

## 01 使用与接口

- [图生成模型与参数手册](usage/图生成模型与参数手册.md)：说明各模型入口、参数、默认值和输出约定，选择生成方法时读。
- [批量图生成与任务存储](usage/批量图生成与任务存储.md)：说明批量配置、预检、续跑和任务记录，准备批量生成时读。
- [原始图交接与读写示例](usage/原始图交接与读写示例.md)：说明 MATLAB 与 Python 如何读取原图并保持原始节点和边身份，对接指标或数据管线时读。
- [原始图存储规范 v1](graph_schema_v1.md)：定义 graph-v1 的目录、字段、身份和校验规则，实现读写或核对正式数据时读；该文件是固定规范入口。

## 02 模型与来源

- [标准图模型与来源说明](models/标准图模型与来源说明.md)：说明标准模型的算法依据、接口和来源约定，核对模型定义时读。
- [合成网络扩展模型与验证说明](models/合成网络扩展模型与验证说明.md)：说明2.1.0新增7模型的参数、参考协议、生成差异和验证入口；NW、Chung–Lu的追加验证也在此索引。
- [作者图模型与已知边界](models/作者图模型与已知边界.md)：说明 EH、RT、RR、RH 作者实现的整理方式、异常路径和方向限制，使用这些模型时读。
- [代码约定与来源维护](models/代码约定与来源维护.md)：说明生成函数约定、随机数恢复和来源指纹维护规则，修改或新增生成器时读。
- [图生成方法与存储规范（LaTeX）](models/图生成方法与存储规范.tex)：汇总图生成方法与存储说明，需要查看方法文稿源文件时读。

## 03 验证记录

- [图生成历史验收记录 2026-09-27](validation/图生成历史验收记录_20260927.md)：保留当时的环境、检查范围和结果，需要追溯该次验收时读。
- [公开版验证说明](../../../docs/validation.md)：本公开副本的检查入口和证据边界；完整历史运行报告不随代码上传。

历史验收记录描述其注明版本和时间的结果，当前接口以使用文档、正式规范和模块说明为准。
