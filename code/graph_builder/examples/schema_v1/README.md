# graph-v1 interoperability examples

Five hand-constructed samples exercise storage and loading:

- Undirected triangle plus isolated node; community labels, coordinates, Unicode metadata and source edge-order mapping.
- Directed reciprocal arcs plus isolated node.
- Three nodes with no edges, stored as a 0-by-2 edge list.
- One directed node with no edges and an explicitly available empty source edge order.
- Relabeled graph with origin_graph_id and a transformation record.

The files are generated by `validation/create_graph_io_examples.m`. They are examples, not a production dataset. Locate them through `manifests/graphs.jsonl`; filenames do not encode model names. Read the schema at `docs/graph_schema_v1.md`.

Run `validation/verify_graph_io.py` with NumPy/SciPy to independently check MATLAB types, topology, graph identity, file checksums and scientific metadata. The default argument points to this directory. Existing identical examples are reused without rewriting their MAT bytes.
