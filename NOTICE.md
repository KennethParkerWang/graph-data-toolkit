This repository is a cleaned source release. It does not currently declare one project-wide open-source license.

The following files retain their upstream notices and source references:

- NetworkX 3.5 reference snippets: `code/graph_builder/sources/standard/networkx_3_5/` (BSD-3-Clause).
- CPython set implementation reference: `code/graph_builder/sources/standard/cpython_setobject.c` with `CPYTHON_LICENSE.txt` (Python Software Foundation License Version 2).

The MATLAB implementations are organized adaptations or independent implementations as described by the model catalogs. Paper PDFs and downloaded author archives are not part of this public package. The source catalogs keep the original URLs and citations so that a user can obtain references from the original providers and verify a local installation.

Before redistribution, check the relevant upstream license and the model-specific source catalog. Do not infer a permissive license from a public download URL.
